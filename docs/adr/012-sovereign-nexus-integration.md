# ADR 012: Integration of Sovereign Nexus and Friction Engine

## Status
Accepted

## Context
The system required a robust mechanism for multi-agent Swarm Dynamics orchestration (L7 Orchestration + Consensus) and conflict resolution through Dialectical Resonance (L7.5). Furthermore, a firewall managing chaotic entropy (L3.5 Containment Kernel + Thermodynamic Auditor) was needed to guarantee system security against bounded variables and unconstrained data influxes.

## Decision
1. **Friction Engine (`src/services/frictionEngine.ts`)**: Implemented to resolve "Cognitive Parallax" between contradictory agent directives. It utilizes a montage synthesis mathematical combination using Golden Ratio weighting (1.618) to output a resolved dialectical vector.
2. **Sovereign Nexus (`src/services/sovereignNexus.ts`)**: Implemented to route agentic Swarm Dynamics operations and guarantee deterministic consensus boundaries for the personas (e.g., KIRA, VIPER, WHIMSY, ALETHEON).
3. **Thermodynamic Auditor (`src/services/thermodynamicAuditor.ts`)**: Implemented an entropy budget controller acting as a TCB firewall, which calculates normalized Shannon Entropy of a state vector and halts execution if it exceeds maximum threshold bounds.

## Consequences
- **Positive**: We have deterministic mathematical bounds protecting the agent execution graph from context rot, stochastic failure, and dialectic contradictions.
- **Negative**: Increases execution overhead as each swarm step requires state probability calculations and Euclidean divergence derivations. The paraconsistent logic framework (e.g., `calculateCognitiveParallax`) must now be rigorously monitored via IVH (Invariant Verification Harness) simulations.
